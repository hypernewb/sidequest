## Implemented boundary · 2026-10-23

`components/taste-starter.tsx` appears only in the seed stage of `components/taste-discovery.tsx`, above manual search in a disclosure. Its three pressed-state buttons are Choose a persona (default active), Paste names and Use a screenshot. List/screenshot candidates initially have no selected entity. Each selected entity exposes an editable Already love / Want to try field (default Already love); Add these interests merges the reviewed selection. The three personas are Nostalgia & games; Music, design & film; Fantasy & alternative music. Their visible seed names and Try this persona action replace the earlier poetic titles and intermediate persona confirmation. The action merges seeds as Want to try and opens the leading-interest question. They remain editable shortcuts, not inferred identities.

The list parser limits a lookup to four names, preserves numeric film titles, rejects profile links/usernames and uses an explicit cultural-community whitelist. There is no provider account/profile fetch. Tesseract loads the self-hosted worker, Wasm core and English/optional Japanese data. PNG/JPEG/WebP images are bounded to 8 MB and 16 million pixels, and remain local temporary previews; OCR yields editable visible text, not artwork recognition. Cancellation and failure leave the manual/list route available. Qloo receives submitted names, not screenshot pixels.

Successful starter merging preserves unrelated picks, replaces list/screenshot duplicates with the reviewed pick/feeling, preserves existing matching picks and feelings for personas, removes imported IDs from skips, and enforces the eight-pick cap before changing the draft. It clears earlier reaction history and decisions plus the previous focus/theme, so Undo choice cannot restore a snapshot from before the import and discard it. A rejected over-cap merge preserves the existing draft. Review my interests opens the editable review; persistence still requires Find my Tokyo sidequest. Applying returns to discovery and automatically runs a Tokyo search; Leave for now exits without applying. Merging never creates official drop follows.

`app/globals.css` reuses the established palette, serif/sans pairing and five-pixel controls. Focused setup uses a single main column up to 960px wide, with the discovery hero, duplicate interest sidebar and explanatory footer hidden by local editing-state rules. Persona rows use open rules with the action alongside the title/seeds on desktop and below them on mobile. The path selector retains moss pressed state and stays in three columns on mobile, with 58px minimum-height buttons there. Review has a flexible entity column and 170px feeling column on desktop; at 640px and below it stacks. The screenshot area has a dashed moss border and a bounded temporary preview. No root tokens, identity assets or global component contract were added; `DESIGN.md` and `.impeccable/design.json` remain incumbent authority.
