# Bring-your-taste starter extension
Operate mode. User requested a friendly top selector for imports/screenshots and editable demo personas, then explicitly chose no credentials: start with screenshots, pasted lists and personas. Extend SideQuest's established field-guide visual world.

First viewport: taste-builder title, short introduction, three clear paths. Paste a list offers music/film/mixed/cultural-community guidance and one-name-per-line text. Screenshot offers a local image control/paste area, optional Japanese text, on-device progress/cancel and editable recognised names. Starting mixes show three open ruled persona rows with real seeds. Signature interaction: existing cultural context becomes exact candidate entities that the user confirms, labels love or curiosity, and merges into the adaptive trail. Nothing is silently persisted. Applying the full trail remains explicit.

Keep serif hierarchy, paper/ink/moss/red, five-pixel controls, open rules, no assets beyond a user's own temporary screenshot preview. Mobile stacks controls and reviews. No live profile scraping or account connections; URLs alone must not look imported. No protected-trait inference or poster-image recognition. Personas are editable demo shortcuts, never personality diagnoses.

Quality bar: path discoverable at the top, real OCR in-browser with image staying local, visible text correction, exact Qloo confirmation, existing-trail merge/cap, live working persona IDs, no horizontal overflow at 1440x1000/390x844. Screenshots are valid viewport crops of entry, list confirmation, persona confirmation and OCR output; not full-page captures. Announcements feature reviewed separately, with a resolved cancellation fix; preserve it.

## Implemented boundary · 2026-10-23

`components/taste-starter.tsx` appears only in the seed stage of `components/taste-discovery.tsx`, above manual search. Its three pressed-state buttons open one list, screenshot or demo-mix path. List/screenshot candidates initially have no selected entity. Each selected entity exposes an editable Already love / Want to try field (default Already love); demo mixes preselect their named seeds as Want to try for review. Only the Add selected action merges the reviewed selection. The three mixes are Pocket worlds, Quiet city wanderer, and Strange worlds, open ears; they are editable shortcuts, not inferred identities.

The list parser limits a lookup to four names, preserves numeric film titles, rejects profile links/usernames and uses an explicit cultural-community whitelist. There is no provider account/profile fetch. Tesseract loads the self-hosted worker, Wasm core and English/optional Japanese data. PNG/JPEG/WebP images are bounded to 8 MB and 16 million pixels, and remain local temporary previews; OCR yields editable visible text, not artwork recognition. Cancellation and failure leave the manual/list route available. Qloo receives submitted names, not screenshot pixels.

Successful starter merging preserves unrelated picks, replaces duplicates with the reviewed pick/feeling, removes imported IDs from skips, and enforces the eight-pick cap before changing the draft. It clears earlier reaction history and decisions plus the previous focus/theme, so Undo choice cannot restore a snapshot from before the import and discard it. A rejected over-cap merge preserves the existing draft. Persistence still requires Use my taste in Tokyo; merging never creates official drop follows.

`app/globals.css` reuses the established palette, serif/sans pairing and five-pixel controls. The path selector has 48px minimum-height buttons with moss pressed state; persona and review rows use open rules. Review has a flexible entity column and 170px feeling column on desktop; at 640px and below it stacks, as do the three path buttons. The screenshot area has a dashed moss border and a bounded temporary preview. No root tokens, identity assets or global component contract were added; `DESIGN.md` and `.impeccable/design.json` remain incumbent authority.
